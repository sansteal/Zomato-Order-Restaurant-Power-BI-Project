# 🍽️ Zomato Order & Restaurant Analysis – Power BI

## 📊 Project Overview
Interactive Power BI dashboard analyzing Zomato orders, restaurant performance, revenue, customer ratings, delivery time, cuisine, and city-level trends.

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## 📌 Key Metrics
- **Total Revenue:** ₹15.57M
- **Total Orders:** 15,000
- **Average Order Value:** ₹1,038
- **Total Restaurants:** 500
- **Cuisines:** 5

## 🔍 Key Analysis
- Top restaurants by revenue
- Orders and restaurants by city
- Revenue trends over time
- Cuisine and price-range analysis
- Delivery time vs. customer ratings
- Revenue by area
- Payment method analysis

## 🎯 Objective
To transform Zomato order and restaurant data into actionable business insights through an interactive Power BI dashboard.
